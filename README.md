# Central de Onboarding Teachy · Instituto Sant'Anna

Página com os roteiros de acesso à Teachy para gestores, professores, famílias e alunos do
Instituto Sant'Anna, com os tutoriais em vídeo de cada público.

- `index.html` — a página (HTML único, logo embutido)
- `_videos/` — tutoriais em vídeo (mp4) e capas; o vídeo só carrega quando a pessoa clica
- `Teachy-Guia-para-estudantes.pdf` — guia para estudantes
